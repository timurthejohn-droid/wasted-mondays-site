# Сайт Wasted Mondays без Тильды

Магазин Wasted Mondays на своём коде. Контент и фото с wastedmondays.ru, интерфейс по мотивам Farfetch,
шрифт Onest (OFL, лежит в `public/fonts`). Node 22, внешних зависимостей нет.
История в git: первый коммит это точная копия Тильды, второй это редизайн.

Запуск: двойной клик по `start.command` или `npm start`, сайт на http://localhost:8850

## Что где

| Путь | Что это |
|---|---|
| `server/index.js` | сервер и маршруты |
| `server/catalog.js` | каталог и расчёт доступного остатка |
| `server/orders.js` | заказы, проверка полей, резерв товара |
| `server/pages.js` | HTML-шаблоны страниц |
| `server/auth.js` | личный кабинет: вход по коду и через Яндекс ID, сессии |
| `server/notify.js` | отправка кодов по почте (SMTP) и SMS (SMS.ru) |
| `data/home.json` | главная: слайды баннера, отбивки со слоганами, лукбук |
| `data/users.json` | пользователи и сессии (персональные данные, в git не попадает) |
| `public/` | стили, скрипт, шрифты, картинки |
| `data/products.json` | товары, выгружены из Тильды 24.09.2026 |
| `data/pages/` | тексты доставки, возврата, контактов, оферты, политики |
| `data/orders.json` | заказы (тестовые, пока нет оплаты) |

## Как устроен резерв

Неоплаченный заказ держит товар 20 минут, оплаченный держит до передачи в МойСклад.
Проверено: 20 одновременных заказов на 2 худи, прошли ровно 2.

## Сделано

- Главная, каталог с фильтром и избранным, карточка товара, корзина, оформление
- Доставка, возврат, контакты, оферта, политика, cookie-баннер
- Старые ссылки Тильды `/catalog/tproduct/...` перенаправляются на новые
- Все страницы закрыты от индексации (мета-тег, заголовок X-Robots-Tag, robots.txt)

## Личный кабинет

Вход без паролей: одноразовый код на почту или по SMS, либо Яндекс ID.
Пока сервисы не подключены, работает тестовый режим: код показывается на странице входа.
Для боевого режима задать переменные окружения и запустить с `NODE_ENV=production`:

| Что | Переменные | Где взять |
|---|---|---|
| Почта | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` | Яндекс 360 или Unisender Go |
| SMS | `SMSRU_API_ID` | sms.ru, раздел API |
| Яндекс ID | `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `SITE_URL` | oauth.yandex.ru, доступы: почта, телефон, имя; Redirect URI `SITE_URL/auth/yandex/callback` |
| За nginx | `TRUST_PROXY=1` | чтобы лимиты считались по настоящему IP |

Защита: код одноразовый, 5 попыток, живёт 10 минут; не больше 8 кодов в час с одного адреса;
в cookie только случайный токен, на сервере его хэш; почта и телефон для входа только подтверждённые.

## Главная

Слайды баннера, отбивки и лукбук меняются в `data/home.json` без правки кода.
Фото для отбивок: человек в полный рост на ровном фоне, `bg` это цвет фона фотографии.

## Осталось

1. МойСклад: товары и остатки брать оттуда, заказы отправлять туда
2. CloudPayments: оплата и чеки (нужны Public ID и API-пароль)
3. Яндекс Доставка: расчёт и выбор ПВЗ в корзине (нужен договор)
4. Промокоды (на Тильде были)
5. Хостинг и перенос домена
